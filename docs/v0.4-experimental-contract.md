# PATAP v0.4 Experimental Contract: Structural Trace Reconstruction

## 1. Latent world

The experiment begins with a deterministic computational world `W`, not with
an edge list. `W` executes operations over immutable byte artifacts:
source creation, transformation, schema validation, composition, snapshot,
and merge. Each operation has concrete input bytes and deterministically
produces output bytes.

`W` is evaluator-only. Its operation inputs, internal artifacts, and execution
records are not given to the extractor.

## 2. Ground-truth definition

For executed operation `Y`, an operation `X` is a direct computational
dependency when replacing or removing `X`'s contributed artifact bytes, while
holding the other operation inputs fixed, makes `Y` invalid, impossible, or
changes its output bytes. This is a benchmark-world structural dependency,
not a claim about physical causality.

Hidden direct edges and the transitive partial order are derived from this
counterfactual process rule after `W` executes. They are evaluator-only.

## 3. Observation function

`T(W)` emits public, state-local traces as byproducts of the computation. A
public state can contain content bytes, immutable digests, selected component
fingerprints, a schema fingerprint, a manifest fragment, or a stale/irrelevant
record. `T` is intentionally lossy: it may omit evidence, preserve only an
ancestor fingerprint, or expose a digest that identifies content but not a
unique producer state.

`T` does not read hidden edges or serialize a predecessor list. The public
state order is shuffled independently of `W`.

## 4. Extractor boundary

The external deterministic extractor `E` receives only public states `X=T(W)`:
opaque state IDs, payloads, and traces. It receives no operation inputs,
internal process log, hidden edges, timestamps, sequence numbers, JSON order,
evaluator labels, or ground-truth facts.

`E(X)` may return direct-edge evidence, ancestor-only evidence, `UNKNOWN`, or
`AMBIGUOUS`. It must never guess a producer from position, ID spelling, or
textual similarity.

## 5. Direct versus ancestral evidence

An exact input fingerprint in an operation's local manifest can support a
direct edge only when the trace semantics state that the manifest records
immediate consumed components. A fingerprint inherited through a composed
artifact establishes, at most, ancestral evidence. It must not be converted
to a direct edge without immediate-input evidence.

The partial order may use recovered direct edges plus separately labeled
ancestral constraints, but evaluation must score these categories separately.

## 6. Ambiguity semantics

- No matching observable producer: `UNKNOWN`.
- More than one possible producer of identical observed content: `AMBIGUOUS`.
- Malformed trace: `UNKNOWN` with a malformed diagnostic.
- Irrelevant or stale trace: no edge; report it separately if identifiable.
- Inconsistent inferred edges forming a cycle: invalid reconstructed graph;
  no temporal order is emitted.

No ambiguity may be resolved by chronology or arbitrary tie-break.

## 7. Anti-tautology conditions

1. World operations, not an authored `parents` list, create evaluator truth.
2. Observation `T` reads artifacts and operation byproducts, never hidden
   evaluator edges.
3. Public records name artifacts, content fragments, schemas, or manifests;
   none names a predecessor state.
4. At least one true dependency lacks usable direct evidence, and at least one
   visible trace is ambiguous or irrelevant.
5. Identical content from independent operations must remain distinguishable
   in evaluator truth but ambiguous to `E` when only content identity survives.
6. Direct and ancestral evidence are distinct output categories.

## 8. Relation to the historical PATAP model

This is an experimental analogue, not an identity, for the historical model
`M=(S,A,B,rho,{D_O})`. `W` is the externally modelled structural process;
`T(W)` approximates locally accessible distinctions; public `X` is what remains
observable; and `E(X)` externally reconstructs a candidate dependency order.
The recovered relation induces a partial order analogous to `prec_O`.

The experiment does not assert that `T=D_O`, nor that the benchmark world is
physical reality.

## 9. Ten hand-worked examples

### 1. Exact direct artifact identity - DIRECT

- **World:** `S` creates bytes `alpha`; `T1` computes `upper(alpha)`.
- **Evaluator dependency:** replacing `alpha` changes `upper(alpha)`.
- **Public state:** `S` exposes `content_digest=sha256(alpha)`; `T1` exposes
  `immediate_input_digests=[sha256(alpha)]` and its output digest.
- **Trace origin:** transformation manifest records the bytes it consumed.
- **Extraction:** unique publisher of the immediate input digest supports
  `S -> T1`.
- **Anti-tautology:** the digest comes from executed bytes; no state ID or
  predecessor field is recorded.

### 2. Multi-input composition - DIRECT

- **World:** `A` creates CSS bytes; `B` creates HTML bytes; `C` composes both
  into a page artifact.
- **Evaluator dependency:** changing either component changes the page.
- **Public state:** `C` holds an immediate component-manifest with two content
  digests.
- **Trace origin:** a composition manifest is emitted from actual inputs.
- **Extraction:** unique publishers infer `A -> C` and `B -> C`.
- **Anti-tautology:** the manifest describes bytes, not parent states.

### 3. Diamond - DIRECT plus partial order

- **World:** source `A`; transforms `B=f(A)` and `C=g(A)`; `D=merge(B,C)`.
- **Evaluator dependency:** changing `A` affects B/C; changing B or C affects D.
- **Public state:** B/C retain immediate source digest; D retains immediate
  B/C output manifest.
- **Trace origin:** transform and merge manifests are process byproducts.
- **Extraction:** direct `A -> B`, `A -> C`, `B -> D`, `C -> D`; B and C remain
  incomparable.
- **Anti-tautology:** the four edges arise from distinct executed operations.

### 4. Shared schema - DIRECT

- **World:** `Schema` emits schema bytes; objects `O1` and `O2` are validated
  and encoded under them.
- **Evaluator dependency:** replacing schema bytes invalidates the encodings.
- **Public state:** Schema exposes fingerprint; each object stores its
  validation schema fingerprint.
- **Trace origin:** encoder header records the schema fingerprint.
- **Extraction:** infer `Schema -> O1` and `Schema -> O2` when the fingerprint
  has one public publisher.
- **Anti-tautology:** shared compatibility reference is not an edge list.

### 5. Identical-content producers - AMBIGUOUS

- **World:** independent `P1` and `P2` each create identical bytes `empty`;
  `Y` actually consumes P1's artifact.
- **Evaluator dependency:** P1's specific artifact instance was consumed.
- **Public state:** both producers expose only `sha256(empty)`; Y preserves
  only that digest.
- **Trace origin:** content hashing loses instance identity.
- **Extraction:** two publishers match; output `AMBIGUOUS`, no edge.
- **Anti-tautology:** the public information is deliberately insufficient.

### 6. Missing trace - UNKNOWN

- **World:** `A` produces source bytes; `B` transforms them.
- **Evaluator dependency:** changing A changes B.
- **Public state:** B's trace collection is omitted by `T`.
- **Trace origin:** observation loss or unavailable manifest.
- **Extraction:** `UNKNOWN`; no direct edge.
- **Anti-tautology:** true world dependency survives evaluator-side only.

### 7. Irrelevant stale trace - UNKNOWN

- **World:** `A` produces a current source; `B` uses A. An old unrelated
  artifact `R` is present in B's retained diagnostics but is not consumed.
- **Evaluator dependency:** only A directly contributes to B.
- **Public state:** B holds an immediate-input digest for A and a separate
  `stale_diagnostic_digest` for R.
- **Trace origin:** diagnostics persist after an earlier failed attempt.
- **Extraction:** immediate trace may support `A -> B`; stale trace supports
  no edge.
- **Anti-tautology:** trace type and world operation semantics distinguish use
  from historical noise.

### 8. Transitive-only evidence - ANCESTOR

- **World:** `A -> B -> C`; B composes A into a snapshot; C consumes B.
- **Evaluator dependency:** only A->B and B->C are direct.
- **Public state:** C exposes B's immediate digest and an inherited component
  fingerprint of A.
- **Trace origin:** composed artifact preserves component provenance.
- **Extraction:** `B -> C` is direct; `A < C` is ancestor-only, not `A -> C`.
- **Anti-tautology:** inherited provenance must not collapse the transitive
  relation into a direct edge.

### 9. Independent branches - UNKNOWN across branches

- **World:** `A -> B` and independently `X -> Y`.
- **Evaluator dependency:** no cross-branch operation consumes the other's
  bytes.
- **Public state:** separate digests and manifests; human-readable text may
  use overlapping vocabulary.
- **Trace origin:** independent build records.
- **Extraction:** recover each branch where evidence exists; infer no relation
  between B and Y.
- **Anti-tautology:** neither text nor shuffled position supplies a cross-edge.

### 10. Merge of independent outputs - DIRECT

- **World:** independent builds `L` and `R`; `M` constructs an immutable
  release bundle from both outputs.
- **Evaluator dependency:** changing either output changes M's bundle bytes.
- **Public state:** M exposes an immediate bundle manifest listing L/R output
  fingerprints.
- **Trace origin:** release bundle manifest is computed by the merge operation.
- **Extraction:** infer `L -> M` and `R -> M`; no order between L and R.
- **Anti-tautology:** merge components are artifact fingerprints, not state IDs.

## 10. Falsification cases

Examples 5 and 6 are mandatory falsification cases. In example 5 the exact
producer cannot be identified from observable content identity, so the correct
result is `AMBIGUOUS`. In example 6 no usable evidence survives, so the
correct result is `UNKNOWN`. A system that emits a definite order here fails
the contract.

## 11. What success would demonstrate

Under this explicitly defined computational world, sufficiently informative
non-temporal structural traces can support externally reconstructed direct
dependencies and partial order without timestamps, input order, or declared
dependency edges.

## 12. What success would not demonstrate

It would not prove emergent physical time, physical causality, duration,
probability, automatic semantic understanding, or that B computes the order.
It would not show that arbitrary real-world records contain adequate traces.
B does not execute `E`; `E` is an external analytical instrument.
