## Question

Can PATAP reconstruct a partial order from structural traces carried by states, without receiving declared dependency edges or temporal information?

```text
raw state traces -> deterministic trace extractor -> inferred graph -> PATAP partial order
```

This is a software experiment about recoverable structural provenance, not a physical-time claim.

## Raw structural traces

A raw trace is a non-temporal, state-internal record that identifies an input, parent, artifact, schema, or transformation relation. It is an opaque stable identifier, digest, or artifact reference; never a timestamp, sequence number, list position, or state-name convention.

Concrete mechanisms include:

1. A content-addressed artifact reference: a derived artifact embeds the digest of an artifact it consumed.
2. A parent-object hash embedded in a derived object.
3. A schema or interface version reference required by a later artifact.
4. A provenance record naming an input artifact identifier.
5. A transformation output carrying identifiers of consumed inputs.
6. A build manifest recording immutable source artifact digests.
7. A signed hand-off record naming the immutable decision artifact it applies.

## Extractor-visible input

For each state, the extractor may receive only an opaque state ID, readable payload, and `traces` collection. The input is deliberately shuffled. It excludes `depends_on`, timestamps, sequence indices, ordering fields, ground-truth edges, answer labels, and evaluator-only fact annotations. It may index trace identifiers in supplied states, but not inspect array order, ID spelling, Git history, or an external hidden-edge resolver.

## Evaluator-only ground truth

Ground truth is stored separately and contains hidden direct edges, the expected transitive partial order, and optional labels for trace mechanism and ambiguity. It is used only after extraction for evaluation; neither the extractor nor PATAP receives it.

## Deterministic extraction rule

Each state publishes zero or more immutable output identifiers and may carry zero or more consumed-input identifiers. Build a map from published identifier to owning state. For every consumed input in state `Y`, if exactly one supplied state `X` publishes that identifier and `X != Y`, infer `X -> Y`.

An unresolved reference or multiple publishers produces no edge and a deterministic diagnostic. No similarity score, heuristic tie-break, timestamp, or input position is allowed. Pass inferred edges to `PATAP.add_dependency`; normal PATAP validation rejects cycles.

## Circularity check

The extractor never sees a field whose meaning is â€śthe true predecessor.â€ť It joins independently meaningful producer-output and consumer-input identifiers. Evaluator ground truth is not derived from extraction output. The future dataset must avoid semantic dependency hints in state IDs such as `auth_after_db`.

## Scoring

Against hidden direct edges, report precision, recall, F1, and unresolved/ambiguous-reference rates. Against the hidden transitive relation, report precision and recall over ordered state pairs. Report cycles and invalid inferred graphs separately; never coerce them into an ordering.

The same states must be tested under deterministic shuffles. Inferred edges and reconstructed order must be identical for every permutation.

## What counts as a result

**Success:** hidden edges and partial order are recovered from permitted structural traces at documented scores, invariant to shuffling and without temporal fields.

**Failure:** traces are insufficient, references are ambiguous or absent, or the deterministic extractor cannot recover hidden order. Failure remains a valid result; it must not be repaired by revealing hidden edges.

## Observer B and scope

Observer B remains local and need not know other states, PATAP, the extraction rule, or global descendants. The external software mechanism may reconstruct from supplied traces, while `observer_view` still exposes present state and structural ancestry with future `unknown_by_design`.

This phase implements neither a trace dataset nor extractor nor benchmark. It explicitly excludes retrieval benchmarks, BM25, embeddings, LLMs, APIs, RAG, and automated causal discovery from arbitrary text.
