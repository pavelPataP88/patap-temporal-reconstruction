# PATAP v0.4 Final Validation Protocol

Protocol revision 1 (`99a38df...`) is invalid because its frozen runner crashed
before measurement. Revision 2 (`ee6f3b8...`) is invalid because it labelled
AMBIGUOUS events from hidden duplicate producers even when `T(W)` had removed
the relevant public trace. Revision 3 freezes the correction before generation
and measurement. A run discovering an implementation error is invalidated; any
correction requires a new protocol freeze, not tuning after results.

## Fixed model

`W` deterministically executes source, unary transform, composition, schema,
and merge operations over concrete immutable byte artifacts. Primary hidden
truth is realized provenance `->use`: an edge exists exactly when an operation
actually consumes a concrete artifact instance. `T(W)` automatically emits an
output fingerprint and immediate-input fingerprints from executed operations.
It may remove a trace, add an inherited fingerprint, add an irrelevant trace,
or replace an immediate fingerprint only in the documented corruption/false
trusted controls.

Public IDs are SHA-256-derived opaque strings. Public states contain no time,
sequence number, parent field, ground-truth edge, or world internals.

## Fixed extractor E

Index public `output_fingerprint` values. For every public immediate-input
fingerprint: one matching public producer yields a direct edge; zero yields
`UNKNOWN`; two or more yields `AMBIGUOUS`; self matches are ignored. Inherited
fingerprints yield ancestor-only evidence and never a direct edge. E does not
read content, IDs semantically, input order, evaluator data, or W.

## Fixed generators and seeds

Primary generator: seed `404001`, 1,000 randomized operation worlds with
chains, forks, joins, independent components and trace faults. Secondary
generator: seed `404002`, 300 layered fan-in/fan-out worlds with different
topology construction. Shuffle seeds are `404100..404104`. Public-ID
replacement is deterministic SHA-256 renaming. Loss levels are 10/25/50/75%;
corruption levels are 5/10/25%.

## Scoring and controls

Score direct and transitive comparable pairs with precision/recall/F1, plus
true positives, false positives, false negatives. UNKNOWN correctness and
AMBIGUOUS correctness are derived only after `T(W)` has materialized the actual
public rows: each *present* immediate fingerprint is expected to be UNKNOWN if
it has zero public producers, or AMBIGUOUS if it has two or more public
producers. A removed trace is not a classification event. Correctness is the
exact fraction of these public-observation events returned by E. Run normal,
trace-removed, five shuffles, opaque-ID replacement, loss, corruption,
identical-content ambiguity, and false-trusted-trace controls on both sets.
For every false-trusted event, the runner asserts that the injected fingerprint
belongs to exactly one real observable artifact that is definitely absent from
the target operation's actual consumed artifact instances. It has the same
public format as an ordinary immediate trace and is intentionally not marked
as stale.

## Project gate

MECHANISM SURVIVES HARD VALIDATION requires primary direct precision >= 0.95
and recall >= 0.80; secondary precision >= 0.90 and recall >= 0.70; invariant
shuffle and opaque-ID controls; near-zero recovery with all traces removed;
and no arbitrary definite edge for ambiguity. Otherwise it is PARTIAL SUPPORT
unless hidden-order leakage or lack of transfer causes FAILS VALIDATION.

This is a computational trace-reconstruction experiment, not a claim about
physical causality, physical time, or what internal observer B computes.
